# 🪙 AliExpress Coin & Coupon Farmer

Автоматизований серверний фармер монеток та купонів AliExpress для GitHub Actions. Працює автономно в хмарі за розкладом ("поставив і забув").

---

## ⚡ Особливості

- **Повна автономність**: Запускається щодня через GitHub Actions без необхідності тримати комп'ютер увімкненим.
- **Підтримка кількох акаунтів**: Можна додати будь-яку кількість акаунтів через окремі секрети (`ALI_COOKIES_1`, `ALI_COOKIES_2` тощо) або єдиний `ALI_COOKIES_JSON`.
- **Двоканальний чекін (PC + Mobile)**: Отримання щоденних нагород за чекін як для веб-версії, так і для мобільного додатку.
- **Комплексний безпечний фарм**:
  - Щоденний чекін (Daily Check-in з підтримкою стріку)
  - Перегляд категорій та товарів (Coins Browse Tasks із суворою безпековою фільтрацією від небажаних підписок чи замовлень)
  - Автоматичний збір доступних промо-купонів у Coupon Center
- **Зручні персональні сповіщення в Telegram**:
  - Стислий, інформативний щоденний звіт (баланс, чекін, таски, зібрані монети).
  - Відображення фіатного еквівалента накопичених та зароблених монет у **USD ($)** та **гривнях (грн)**.
- **Анти-детект система**:
  - Випадковий зсув часу старту (0..30 хв)
  - Рандомізовані затримки між кожним запитом (2–5 секунд)
  - Ротація сучасних User-Agent рядків
  - Імітація поведінки звичайного браузера

## 🌍 Якщо ви проживаєте в іншій країні

- **Міжнародний домен:** Авторизуйтесь на **[https://www.aliexpress.com](https://www.aliexpress.com)** (саме глобальна версія `.com`).
- **Універсальна конвертація:** AliExpress оцінює монети однаково у будь-якій точці світу: **100 монет = $1.00 USD** (1 монета = $0.01). Звіт завжди показує доларову вартість ваших монет.
- **Часовий пояс:** Запуск налаштовано за UTC (09:09 UTC та 14:09 UTC). Сповіщення приходитимуть з урахуванням вашого місцевого часу.
- **Капча Alibaba WAF:** Якщо вхід із серверів GitHub тимчасово вимагатиме капчу, відкрийте мобільний додаток або сайт AliExpress зі свого звичайного пристрою та здійсніть чекін чи посуньте слайдер вручну один раз для зняття перевірки.

## 🚀 Швидкий старт (Налаштування за 5–7 хвилин)

### Крок 1: Створення репозиторію на GitHub

> [!IMPORTANT]
> **Рекомендується створювати саме ПРИВАТНИЙ (Private) репозиторій!**
> У приватному репозиторії сторонні користувачі не зможуть побачити ваші звіти запусків, логи та баланси монет.

1. Зареєструйтесь на [GitHub](https://github.com).
2. Натисніть **+** у правому верхньому кутку ➔ **New repository**.
3. Введіть назву (наприклад, `ali-farmer`), оберіть **Private** і створіть репозиторій.
4. Завантажте файли проекту в створений репозиторій.

---

### Крок 2: Створення Telegram-бота для звітів

1. Відкрийте Telegram і знайдіть бота **[@BotFather](https://t.me/BotFather)**.
2. Надішліть йому команду `/newbot`.
3. Введіть назву та юзернейм для бота (наприклад, `my_ali_coins_bot`).
4. Скопіюйте отриманий токен (це ваш `TELEGRAM_BOT_TOKEN`).
5. Дізнайтеся свій числовий ID через бота **[@userinfobot](https://t.me/userinfobot)** (це ваш `TELEGRAM_CHAT_ID`).
6. **Обов'язково:** відкрийте вашого щойно створеного бота в Telegram і натисніть кнопку **START** (`/start`), щоб дозволити йому писати вам повідомлення!

---

### Крок 3: Отримання Cookies з браузера

Вам знадобиться повний рядок `Cookie` активної сесії:

- **Спосіб А (через розширення, найпростіший):**
  1. Встановіть розширення **Cookie-Editor** (для Chrome, Firefox або Edge).
  2. Відкрийте [aliexpress.com](https://www.aliexpress.com) та увійдіть в акаунт.
  3. Відкрийте Cookie-Editor ➔ натисніть **Export** ➔ **Export as Header String**.
- **Спосіб Б (через DevTools F12):**
  1. Увійдіть на [aliexpress.com](https://www.aliexpress.com).
  2. Натисніть `F12` (або `Ctrl + Shift + I`) ➔ перейдіть у вкладку **Network**.
  3. Оновіть сторінку (`F5`).
  4. Натисніть на перший запит (`aliexpress.com`) ➔ у вкладці **Headers** у розділі **Request Headers** скопіюйте повне значення заголовка **Cookie**.

> [!CAUTION]
> Після копіювання cookies **НЕ натискайте "Вийти" (Log out)** на сайті AliExpress, інакше сесія анулюється. Просто закрийте вкладку браузера.

---

### Крок 4: Додавання в GitHub Secrets

1. У вашому репозиторії перейдіть у: **Settings** ➔ **Secrets and variables** ➔ **Actions**.
2. Натисніть **New repository secret**.
3. Додайте такі секрети:

| Назва секрету | Значення |
| :--- | :--- |
| `ALI_COOKIES` | Скопійований рядок cookie |
| `TELEGRAM_BOT_TOKEN` | Токен вашого бота від @BotFather |
| `TELEGRAM_CHAT_ID` | Ваш числовий ID від @userinfobot |

*(Опційно: для додаткових акаунтів можна додати `ALI_COOKIES_1`, `ALI_COOKIES_2` тощо).*

---

### Крок 5: Тестовий запуск

1. Перейдіть на вкладку **Actions** у вашому репозиторії.
2. Якщо репозиторій було форкнуто, натисніть **"I understand my workflows, go ahead and enable them"**.
3. Виберіть воркфлоу **AliExpress Daily Farm** у лівому меню.
4. Натисніть кнопку **Run workflow** ➔ **Run workflow**.
5. Зачекайте 1-2 хвилини — ви отримаєте сповіщення у свій Telegram-бот!

---

## ⏰ Розклад роботи

За замовчуванням воркфлоу запускається автоматично щодня:
- **09:09 UTC** (основний щоденний запуск)
- **14:09 UTC** (резервний запуск для перевірки та добору монет)

Перед кожним автоматичним запуском скрипт самостійно додає випадковий зсув 0..30 хв для максимальної природності дій.
