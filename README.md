# 🪙 AliExpress Coin & Coupon Farmer

Автоматизований серверний фармер монеток та купонів AliExpress для GitHub Actions. Працює автономно в хмарі за розкладом ("поставив і забув").

---

## ⚡ Особливості

- **Повна автономність**: Запускається щодня через GitHub Actions без необхідності тримати комп'ютер увімкненим.
- **Підтримка кількох акаунтів**: Можна додати будь-яку кількість акаунтів через окремі секрети (`ALI_COOKIES_1`, `ALI_COOKIES_2` тощо).
- **Комплексний фарм**:
  - Щоденний чекін (Daily Check-in)
  - Перегляд категорій та товарів (Coins Browse Tasks)
  - Збір доступних купонів (Coupon Center)
- **Анти-детект система**:
  - Випадковий зсув часу старту (до 30 хв)
  - Рандомізовані затримки між кожним запитом (2–5 секунд)
  - Ротація сучасних User-Agent рядків
  - Імітація поведінки звичайного браузера

---

## 🚀 Швидкий старт (Налаштування за 5 хвилин)

### Крок 1: Отримання Cookies з браузера

1. Відкрийте браузер (Chrome, Edge тощо) і перейдіть на [aliexpress.com](https://www.aliexpress.com).
2. Переконайтеся, що ви **авторизовані** у своєму акаунті.
3. Натисніть клавішу `F12` (або `Ctrl + Shift + I`), щоб відкрити **DevTools**.
4. Перейдіть на вкладку **Network** (Мережа).
5. Оновіть сторінку (`F5`).
6. У списку запитів натисніть на найперший запит (наприклад, `aliexpress.com`).
7. У правій панелі знайдіть розділ **Request Headers** ➔ рядок **Cookie**.
8. Скопіюйте все значення рядка `Cookie:` (це довгий рядок з токенами сесії).

---

### Крок 2: Додавання в GitHub Secrets

1. Створіть новий публічний або приватний репозиторій на GitHub та завантажте цей код.
2. У вашому репозиторії перейдіть у:
   **Settings** ➔ **Secrets and variables** ➔ **Actions**.
3. Натисніть **New repository secret**.
4. Додайте секрети:
   - Якщо **один акаунт**: назва `ALI_COOKIES`, значення — скопійований рядок cookie.
   - Якщо **декілька акаунтів**:
     - `ALI_COOKIES_1` — cookies першого акаунта
     - `ALI_COOKIES_2` — cookies другого акаунта
     - і т.д.

> [!NOTE]
> Секрети на GitHub зашифровані. Ніхто сторонній не зможе прочитати ваші cookies у публічному репозиторії.

---

### Крок 3: Перший тестовий запуск

1. Перейдіть на вкладку **Actions** у вашому репозиторії.
2. Виберіть workflow **AliExpress Daily Farm** у лівому меню.
3. Натисніть кнопку **Run workflow** ➔ **Run workflow**.
4. Відкрийте запущений процес та перегляньте логи виконання.

---

## 💻 Локальний запуск (для тестування)

Якщо ви хочете перевірити роботу скрипта на своєму комп'ютері:

1. Встановіть залежності:
   ```bash
   pip install -r requirements.txt
   ```
2. Вкажіть cookies та вимкніть початкову 30-хвилинну паузу:
   - **PowerShell (Windows)**:
     ```powershell
     $env:ALI_COOKIES="тут_ваш_cookie_рядок"
     $env:SKIP_RANDOM_SLEEP="1"
     python -m src.main
     ```
   - **Bash (Linux / macOS)**:
     ```bash
     export ALI_COOKIES="тут_ваш_cookie_рядок"
     export SKIP_RANDOM_SLEEP="1"
     python -m src.main
     ```

## ⏰ Розклад роботи

За замовчуванням workflow запускається щодня:
- **08:00 UTC** (11:00 за київським часом влітку / 10:00 взимку)
- Перед виконанням скрипт автоматично додає випадкову затримку 0..30 хв, тому точний час щодня різний.

Змінити розклад можна у файлі [`.github/workflows/farm.yml`](file:///.github/workflows/farm.yml) у блоці `cron: '0 8 * * *'`.
